# MindLex - Phase 1: Backend Setup & Run Instructions

1. `cp .env.example .env` (configure MONGODB_URI, GEMINI_API_KEY, and GEMINI_MODEL)
2. `npm install`
3. `npm test` (runs Vitest unit tests covering all Merge Service specifications)
4. `npm run dev` (starts full-stack server on http://localhost:3000)
